# Glossary

- **ADC** — Antibody-Drug Conjugate / 항체-약물 접합체
- **DAR** — Drug-to-Antibody Ratio / 항체당 약물 결합 수
- **PU Learning** — Positive–Unlabeled Learning / 양성-미표지 학습
- **UCB** — Upper Confidence Bound / 상한 신뢰경계 기반 acquisition
- **EI** — Expected Improvement / 기대 향상량
- **DBTL** — Design–Build–Test–Learn
- **PBPK** — Physiologically Based Pharmacokinetic modeling
- **QSP** — Quantitative Systems Pharmacology
