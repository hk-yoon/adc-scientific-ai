# Changelog

All notable changes to this educational project will be documented here.

## [0.1.0] — 2026-10-06

### Added

- Ten executable educational notebooks covering ADC target discovery through ADC construct representation.
- TCGA/GTEx-style tumor–normal feature engineering examples.
- HPA-style normal-tissue safety filtering examples.
- Rule-based, supervised ML, and Positive–Unlabeled target ranking workflows.
- Simulated wet-lab feedback and active-learning / closed-loop examples.
- ADC construct representation spanning target, antibody, linker, payload, DAR, and conjugation features.
- Korean README summary.
- Public-data source and licensing guidance.
- Reproducibility, release-audit, and publishing documentation.

### Notes

- v0.1.0 is an educational and research prototype.
- Bundled biological values and wet-lab outcomes are synthetic/simulated unless explicitly stated otherwise.
- The release is not a clinical, regulatory, or validated drug-development decision system.
